PROJECT NOTES 02 STUDIES

01FLEXBOX

The responsive card

Exploring how a flexible row and a column inside each card keep different amounts of content aligned.

Read the build notes +

The container stretches its cards to equal heights. Each card is a flex column, and margin-top: auto pushes its link to the bottom. Below 768px, the row becomes a column.

See the card row ↗
02CSS GRID

The adaptable gallery

Giving nine images a consistent rhythm, from a wide desktop canvas to a small mobile screen. Captions stay accessible on touch screens, too.

Read the build notes +

The gallery uses repeat(3, 1fr), then two columns below 1000px and one below 520px. Images use object-fit: cover. Captions fade in on hover or keyboard focus.
